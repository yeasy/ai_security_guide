# 第十一章 智能体安全基础

从本章起进入智能体安全篇。智能体把模型与工具、记忆和外部环境相连，使其能够自主规划和行动；安全问题随之从“模型会说什么”扩展为“系统会做什么”。本篇共四章：本章介绍智能体的实现结构、威胁模型和贯穿全篇的主线；[第十二章](../12_agent_attack_surface/README.md)分析攻击入口；[第十三章](../13_agent_architecture/README.md)讨论边界划分与架构防御；[第十四章](../14_agent_practice/README.md)以编码智能体、综合案例和全景图收尾。希望先了解全貌的读者可从 [14.5](../14_agent_practice/14.5_security_panorama.md) 读起。

## 学习目标

读完本章，读者应能：

- 说明智能体调用循环中模型读到什么、输出什么，指出外部内容从哪三处进入上下文、真实执行发生在哪里。
- 区分模型的随机出错与被操纵，说明二者为何后果相同、差别在哪里，以及为何都要经过同一道闸。
- 对一个给定的智能体逐项检查不可信内容 [A]、敏感访问 [B]、对外动作 [C]，判断攻击链是否成立、闸应取何种强度、可采用哪种防御形态。
- 用 CAS 原理说明通用性、自主性、安全性任取两项时必须放弃哪一项。
- 为高风险动作规划权限治理与审计记录：危险组合规则、按可逆性分级的人工确认，以及能回答“哪段输入引起了哪个动作”的追踪。
- 说明 AP2 如何用开放与关闭授权凭证把损失限定在用户签署的约束之内，以及部署方仍需自行补上的累计预算与可信状态。

## 本章结构

- **[11.1](11.1_agent_implementation.md) 智能体的实现结构与调用过程**：上下文窗口里有什么、循环怎么跑、各家术语落在循环的哪个位置，由此能推出哪四条安全结论？
- **[11.2](11.2_threat_model.md) 威胁模型：不可信来源与攻击目标**：哪些来源能影响模型的判断，各自如何防御，攻击者想达到什么目标？
- **[11.3](11.3_unreliable_executor.md) 不可靠执行者模型**：模型既会随机出错又会被操纵时，系统应如何约束它？
- **[11.4](11.4_lethal_trifecta.md) 致命三要素与 Rule of Two**：什么条件下攻击链成立，闸需要多强，防御有哪几种形态？
- **[11.5](11.5_cas_principle.md) CAS 原理**：为什么通用性、自主性、安全性不可兼得，放弃通用性最常见的做法是什么？
- **[11.6](11.6_typical_failures.md) 三类典型失效：被操纵、随机出错、权限膨胀**：控制流劫持、幻觉驱动的工具调用和过度自主权分别如何造成损失？
- **[11.7](11.7_permission_governance.md) 权限治理**：工具增多后如何控制权限组合，人工确认如何分级？
- **[11.8](11.8_dark_code.md) 暗码与可追溯性**：运行时行为为什么难以追溯，审计要记录什么、才能回答“哪段输入引起了哪个动作”？
- **[11.9](11.9_web3_agents.md) 高后果场景：资金操作**：在后果不可逆的链上转账与智能体支付中，闸应如何落地？

各节的顺序是：先讲智能体如何运行（11.1）和威胁来自哪里（11.2）；再给出贯穿全篇的主线，即安全模型（11.3）、判断闸强度的判据（11.4）和安全的代价（11.5）；随后讨论典型失效（11.6）及相应的权限治理与追溯（11.7、11.8）；最后把这些方法用于资金操作这一高后果场景（11.9）。

OWASP 智能体安全威胁清单（T1–T17）、*OWASP Top 10 For Agentic Applications 2026*（ASI01–ASI10）与本书各章节的逐条对照见[附录 D](../16_appendix/D_owasp_agentic_crosswalk.md)。

> **⚠️ 道德边界**：本篇对工具调用滥用、记忆投毒、多智能体信任链破坏的剖析，用于让智能体开发者识别并修复自身系统的安全弱点；针对未经授权的他方系统执行类似攻击违反法律与服务条款。完整声明见 [§4 章首道德边界与负责任披露说明](../04_prompt_injection/README.md)。
