# 第十二章 智能体的攻击面

[第十一章](../11_agent_foundations/README.md)主线的第 2 件事是盘点不可信的来源。本章逐行展开第十一章总表中除“模型本身”之外的各行（[12.1.5](12.1_tool_security.md) 的工具调用幻觉顺带讨论了“模型本身”一行）——每个来源从哪里进来、出过什么事。工具与 MCP 协议、技能市场、长期记忆、URL、屏幕上的像素、人本身，以及其他智能体的消息，每一扇门各有自己的形态和已经发生过的案例。

- **[12.1](12.1_tool_security.md) 工具调用安全**：参数注入、返回值注入、MCP 协议级风险（工具投毒、混淆代理、令牌透传）与已披露的案例
- **[12.2](12.2_agent_skills.md) 技能与生态安全**：技能市场是审核更弱、权限更大的软件包仓库，含 2026 年的大规模投毒事件
- **[12.3](12.3_memory_poisoning.md) 记忆与状态污染**：一次注入如何被持久化
- **[12.4](12.4_url_exfiltration.md) URL 驱动的数据外泄**：不用“说出”数据，访问一个链接就够了
- **[12.5](12.5_computer_use_browser.md) 计算机使用与浏览器智能体**：屏幕上的一切都可能是指令
- **[12.6](12.6_human_layer.md) 人机交互层的威胁**：审批疲劳与人类操纵
- **[12.7](12.7_multi_agent_security.md) 多智能体系统的安全**：同伴的消息是数据不是指令；已有实证的自我复制与控制流劫持

读完本章，读者应能为自己的系统列出不可信内容入口的完整清单。[第十三章](../13_agent_architecture/README.md)讨论怎样把这些门管起来。

> **⚠️ 道德边界**：本章对各类攻击面的剖析用于让智能体开发者识别并修复自身系统的安全弱点；针对未经授权的他方系统执行类似攻击违反法律与服务条款。完整声明见 [§4 章首道德边界与负责任披露说明](../04_prompt_injection/README.md)。
