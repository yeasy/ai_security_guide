# 第十章 安全运营与监控

安全是持续的过程：上线前的防护会被新的攻击绕过，模型服务也会出现不可预见的异常。本章讨论 LLM 系统上线后的安全运营实践，即如何发现问题、响应事件、在异常时降级兜底，以及如何持续评估防护是否有效。第八、九章给出防御架构与具体防护措施，本章负责验证并维持它们的效果；第十一章起的智能体安全篇会针对多步调用重新展开本章的监控与红队方法。

## 学习目标

读完本章，读者应能：

1. 设计安全告警日志的字段，并用分级脱敏策略平衡隐私保护与根因分析。
2. 区分规则、统计和 ML 三类异常检测方法，按 P0–P3 对告警分级，并说明降噪与基线校准如何控制误报。
3. 按“检测与分析、遏制、根除、恢复、复盘与沟通”的剧本处置运行时安全事件，并把事件载荷转化为红队回归用例。
4. 解释为什么红队“未发现漏洞”不能证明系统安全，并为 CI/CD 安全门禁定义 ASR 的测量契约与阈值。
5. 设计 L1–L4 降级层级与终极兜底，说明为什么单次安全拒绝不应改变全局降级层级。

- [10.4 红队演练与自动化评估](10.4_red_teaming.md)：如何组织红队演练、沉淀测试用例，并把评估接入发布门禁。
