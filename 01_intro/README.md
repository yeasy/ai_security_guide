# 第一章 大语言模型安全导论

大语言模型（Large Language Model，LLM）已进入客服、编程、内容创作、知识问答等生产场景，安全风险也随能力提升而不断演化。本章是全书的开篇，回答三个问题：LLM 是什么，它为什么需要专门的安全工作，它面临哪些威胁。本章建立的认知框架是后续各章的起点：第二章深入模型架构、训练与推理的技术细节，第三章用 OWASP、NIST 等框架系统化地组织本章列出的威胁。

## 学习目标

读完本章，读者应能：

1. 说明 LLM 的四项核心技术特点（概率生成、上下文依赖、知识固化与幻觉、黑箱特性），并指出它们分别对应哪些安全风险。
2. 结合真实事故与漏洞披露，说明 LLM 安全事件的经济、声誉、法律和社会影响，以及安全性与可用性之间的取舍。
3. 区分 LLM 安全中沿用的传统安全原则（纵深防御、最小权限等）与 LLM 特有的挑战（模糊的输入边界、指令与数据混淆、概率性输出等）。
4. 从攻击阶段、安全目标和攻击向量三个维度对 LLM 威胁分类，并说出 OWASP LLM Top 10 的十个风险类别。
5. 针对一个 LLM 应用回答威胁建模的四个问题：核心资产是什么、信任边界在哪里、模型能做什么、最高风险场景是什么。
